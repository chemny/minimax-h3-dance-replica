# 舞蹈表演分析与提示词

## 对陌生视频的观察

先读取真实时长和帧率，按原速度建立统一时间轴。用4fps接触表覆盖整段，快速转身、入画、手势与表情变化处加密至8—12fps或逐帧。0.25秒采样不能证明0.05秒级动作边界；边界标注为约值，必要时回看邻帧。切镜或遮挡是分析边界，不是凭空补动作的理由。

逐段记录：
- 屏幕位置、人物大小、是否靠近镜头；区分人物移动与相机移动。
- 头、肩、躯干朝向，手臂/手掌位置、支撑与重心，以及如何进入下一姿势。
- 转身从哪一侧开始、是同方向完成一圈还是转回、何时背身与回正。左右说明采用画面左右还是人物自身左右。
- 表情分成眼睑、嘴部、视线、头部运动。低头不等于闭眼，张口不等于说了某句台词。
- 不可见信息与置信程度：背身不写正脸表情，手被挡住不猜指形。

以变化点分段，不设固定段数；不要把旧案例的动作、时间点或表情当成新视频的模板。

## 表情不过度渲染

依据原片幅度写“嘴角略上扬、嘴唇闭合”等可见事实。常态只写一次，各段只写变化。明显大笑的原片可写明显大笑，不能一律改成微笑或面无表情。不要反复叠加“甜美、俏皮、妩媚、灿烂”。每个短暂张口、闭眼或侧视事件都要记录结束/恢复；不能为了增加表情强行添加眨眼。表情文字可影响内容，但不保证视线和嘴型精确同步。

## 记录格式

提供 `performance.json`，供 `scripts/prompt.py` 编译。`identity`仅描述目标人物，`scene_camera`描述应保留的场景与镜头，不能把原演员的外观或照片背景错误带入。

```json
{
  "duration_seconds": 2.0,
  "identity": "保持用户目标照片中的同一成年人物、发型与服装。",
  "scene_camera": "固定机位，保持参考视频的背景与取景。",
  "baseline_expression": "依据原片记录的常态表情；不要额外放大。",
  "segments": [
    {"start": 0, "end": 1, "body": "实际观察到的入画动作与姿势变化。", "expression": "本段真实可见的嘴部或眼睑变化；没有变化可以留空。", "gaze": "真实可见的视线方向。", "visibility": "visible", "confidence": "checked"},
    {"start": 1, "end": 2, "body": "实际观察到的背身及手臂运动。", "expression": "", "gaze": "", "visibility": "back", "confidence": "checked"}
  ]
}
```

这只是字段格式示例，不是可直接用于新视频的动作模板。时间段应连续覆盖目标片段。`visibility`为`visible/back/occluded/out_of_frame`；`confidence`为`checked/uncertain`。未核实段落先回看，编译器拒绝不确定记录进入生成提示词；不可见脸部时不编造表情或视线。

编译后的自然语言保留时间边界和段内衔接；输入分析记录不应包含给 Agent 的命令。复核表与提示词分别保存，后续只改提示词时应复用已核实的素材和控制视频。
