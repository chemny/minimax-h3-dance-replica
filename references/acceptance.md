# 通用验收与同步对照

## 输入和端点

- 核对参考视频的完整时长、帧率、画幅、切镜与遮挡，建立源视频时间轴；人物照、服装图分别标明用途。
- 首尾帧分别并排比较原片对应帧：头与身体朝向、手位、关节、人物大小、画面位置、背景、镜头角度和遮挡。画外部分保持画外，不为展示新人物而补全。
- 在面部可见的帧与身份照比较面容、发型和配饰；首帧没有脸时只能检查构图/服装，不能据此宣称身份匹配。
- 与服装参考比较材质表现、颜色、剪裁、肩带、领口、裙长与配饰。用户更正材质/款式后更新本任务说明，不能沿用旧版本。
- 图片任务成功、图片能打开，只说明执行成功。姿态、身份或构图不合格的端点不送入视频；允许的误差须结合用户目标说明，不用未经认可的数值阈值放行。

## 成片必须看完整段

以实际动作变化点检查起始、关键姿势、过渡和恢复；不只看首尾与漂亮帧。每个新视频重新定位事件，不套用历史案例秒数。快速动作处密集取样或逐帧查看。

| 维度 | 核对内容 |
|---|---|
| 技术完整性 | 文件可完整解码；尺寸、帧率、交付帧数与约定相符；没有静默裁片 |
| 人物 | 面容、发型、衣服、配饰在整个过程中保持；背身不强行出现正脸 |
| 动作与姿态 | 启动时刻、方向、路径、关键姿势、幅度、屏幕位置、重心及结束/恢复时刻 |
| 表情与视线 | 仅按源片可见信息核对幅度、方向和起止；无法观察时标不确定，不猜 |
| 场景与镜头 | 背景几何、主体大小、机位、透视及镜头移动；区分人物移动与镜头运动 |
| 时序与画质 | 闪烁、残影、突变、手部异常及衣物/头发中途变形 |
| 声音 | 保留约定音乐、音画同步；逐包相同时才声称无转码保留 |

每项记录`pass / fail / uncertain / not_applicable`及对应时间/证据。没有检查的项目不能当作通过；不适用须说明原因。无法可靠测量时描述可见偏差，不杜撰身份或动作分数。

分别给出三层结论：**执行是否完成、人物是否保持、动作是否复刻达标**。后两项根据用户目标和全片证据判断，不因执行完成自动通过。当前后端若没有专门的视线/嘴型硬控制，不能仅凭提示词写了这些内容就宣称已控制。

## 对照脚本

```bash
python3 "$SKILL/scripts/compare.py" --source "$SOURCE" --result "$RESULT" --out "$CASE/comparison" --performance "$CASE/performance.json"
```

统一入口也可执行`dance.py compare --config "$CONFIG"`；`run`完成生成和音乐恢复后会制作对照，但不会自动填写视觉验收。

脚本在客户端运行，只处理已有视频，不提交生成。需要FFmpeg/FFprobe及Pillow。输出左原片、右成片的`comparison.mp4`、带时间的接触表，以及`verification.json`和`acceptance.json`。

对照保持各自原始播放速度和从起点计的内容时间，不自动寻找最佳平移或变速；仅为共同播放采样到输出帧率，保持比例加边框。两片时长不同会在较短片末尾保持最后一帧，并在报告中记录补尾范围，不把补尾当实际动作。技术上存在的原始时间戳差异也记录在元数据，不暗中用其修正动作。

独立脚本默认比较完整源片；若用户只要求原片起始的一段，可显式传`--source-duration`，统一入口从本任务metadata读取已约定时长。截取范围会记录在报告中，不能默默用未生成的后半段评判动作。

默认在约定片段均匀取样，并从本任务performance.json的段落边界加密取样；变化点不是正确性证明。Agent仍须回看整段与快动作邻帧。脚本只生成技术核验和待填的视觉清单，不能自动判定人物/动作通过。原始声音从结果片复制；不兼容MP4时明确失败，不悄悄转码。Agent完成视觉核对后填写验收文件。

对照输出固定保留源素材摘要、取样时刻和补尾说明，参数不含案例人物、动作秒数或固定路径。

## 引导边界、跳变诊断与交付决定

- 对首帧、尾帧及任何额外图片引导位置，检查相邻连续帧的人物大小、朝向、姿态与背景；静态引导帧正确不代表过渡连续。没有额外引导时仍检查动作突变处和首尾衔接。
- 出现“跳帧”观感时，先检查解码、时间戳与帧间隔，再逐帧核对画面，区分播放/封装问题与生成内容跳变。相邻像素差只辅助定位，不能独立判定质量或原因。
- 动作保持与人物保持分别判断：动作更连续不能抵消面容、发型、服装或配饰漂移；人物更像也不能证明动作对齐。记录改善与退步，不合并成未经定义的总分。
- 用户明确接受版本后，记录交付文件、已知限制和停止测试的决定，不自行追加生成。用户接受与技术/视觉检查结果分别保存，不能把接受交付改写成问题已解决；用户后续明确提出新验证时按新任务执行。

## 多段接缝

检查共享边界是否引用同一张图片；拼接只移除重复的共享帧，不改变原速度。核对总帧数、整片音轨与所有接缝相邻帧的姿态、方向、动作速度、衣服、光照和背景。共享端点相同不能代替接缝自然度验收。
