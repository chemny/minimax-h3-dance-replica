# Codex人物图和首尾帧编辑

本技能用于Codex；图片环节使用会话自带图像工具，不接入Qwen Image 2.1。Python只准备请求、检查文件和保存核对结果，不能调用会话工具，也不要求图片模型API密钥。

## 身份、服装和动作参考分工

每次编辑前为每个输入明确指定角色；同一张图可承担多个已约定角色，但不能默认混用：

| 素材 | 提供的信息 | 不应带入的信息 |
|---|---|---|
| 原视频对应帧 | 姿势、朝向、手位、人物大小与位置、背景、机位和遮挡；作为编辑底图 | 待替换演员的脸、发型和服装 |
| 身份照 | 目标成年人物的面容、发型及已选定配饰；没有单独服装图时兼作服装参考 | 摆拍姿势、身体位置、相机角度和照片背景 |
| 独立服装参考（可选） | 用户指定的材质表现、颜色、剪裁、肩带、领口、长度和服装配饰 | 该图模特的脸、发型、身材、姿势及背景 |

有独立服装参考时只从该图取服装，仍由身份照确定人物。用户最新明确选择优先，冲突且会影响结果时澄清；不替用户把材质、裙长、领口或发型改成其他版本。记录本任务的素材角色与文字要求，不把当前人物或衣服固化进技能。

## 操作和核对

1. 核实会话图像编辑能力。已有合格人物照直接复用；缺工具时报告或使用用户已有端点，不自动切换模型。
2. 运行`dance.py prepare`取得真实首尾帧，再运行`anchors`输出`anchors/request.json`。配置`identity`提供身份照，`wardrobe_reference`可选提供衣服图，`wardrobe_description`可记录用户的文字更正；这些都是任务参数。
3. 调用Codex图像工具时显式标注编辑底图、身份参考及服装参考。逐张编辑；不得复制人物照站姿、补全画外身体、拉远镜头、把背身改正脸或另造人物。
4. 保存工具真实返回的文件为约定端点路径。小图复制到任务目录用于交付；不伪造路径或复制大文件备份。仅允许明确的等比尺寸归一化，不能用裁切掩盖错误构图。
5. 按 [acceptance.md](acceptance.md) 与源帧、身份照、衣服图分别核对。图片任务成功只说明执行完成，不证明身份、姿势和构图正确。首帧没有可见脸时不据此判定身份一致。
6. 合格后Agent执行`approve --item anchors`记录文件摘要；用户要求先确认时等待用户，其余情况由Agent完成检查。尚未检查、不合格或不确定的图片不能直接送入视频。

## 图像工具拒绝或失败

- 区分能力缺失、临时服务/网络错误、内容安全检查拒绝；报告实际原因和已生成/未生成的素材，不把一次拒绝说成整个模型永远不可用，也不承诺重复调用必能成功。
- 安全检查拒绝时，不隐藏、裁切敏感参考或反复改写来规避检查。可以说明可继续的合规调整方向；改变用户已选衣服、人物或其他关键要求，先获得对应授权，不擅自降低领口要求、加长裙子或更换女主。
- 用户已经明确授权具体调整时，按该调整继续，不重复确认。一般生成授权不等于允许任意改变服装或换模型。用户后来修正款式，以其最新要求为准，并更新任务记录/建立新任务。
- 不静默切换Qwen、第三方图片API或新增模型。已有素材保留，缺失端点或失败端点不进入视频。正常技术重试遵循工具能力和任务状态，提交结果未知时不盲目重复。

上述规则约束素材分工、授权和验收，不保证图像工具能精确保持姿势或面容。历史成功/失败及具体参数只在 [evidence.md](evidence.md) 的案例记录中查看。
